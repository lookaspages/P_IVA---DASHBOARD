P.IVA Dashboard — PWA

PUBBLICAZIONE GRATIS CON GITHUB PAGES
1. Crea un nuovo repository GitHub, ad esempio piva-dashboard.
2. Carica TUTTI i file contenuti in questa cartella nella root del repository.
3. In GitHub apri Settings > Pages.
4. In Build and deployment scegli Deploy from a branch.
5. Branch: main, cartella: / (root), quindi Save.
6. GitHub mostrerà l'indirizzo pubblico della dashboard.

INSTALLAZIONE SU IPHONE
1. Apri l'indirizzo GitHub Pages in Safari.
2. Tocca Condividi.
3. Tocca Aggiungi alla schermata Home.
4. Apri P.IVA dalla nuova icona.

I dati inseriti dalla dashboard restano nel localStorage del browser del dispositivo. Non vengono sincronizzati automaticamente tra dispositivi e cancellare i dati di Safari può rimuoverli.
