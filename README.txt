P.IVA Dashboard v3 — prospetto spese storico.

Carica TUTTI i file e la cartella icons nella ROOT del repository GitHub Pages (non caricare la cartella contenitore).
In GitHub: Code → Add file → Upload files → trascina il contenuto di questa cartella → Commit changes. Il link resta invariato.

ATTENZIONE: i dati degli incassi aggiunti/modificati nell’app sono salvati nel localStorage del browser, non su GitHub. Prima di cambiare browser o dispositivo, usa «Esporta dati». Non cancellare i dati di Safari.

Le spese sono un prospetto storico statico dell’analisi precedente; non sono sincronizzate con banca o PayPal.
